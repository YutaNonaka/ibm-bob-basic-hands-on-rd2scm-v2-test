## 背景・目的

`qa.md` に英語で記載されたFAQ(Bobに関するよくある質問)を、日本語で閲覧できるFAQサイトとして公開できる形にする。バックエンドを持たない静的サイトとし、`index.html` をブラウザで開くだけで利用できるようにする。

## 現在の挙動

リポジトリには FAQ の元データ `qa.md`(英語)と `specs/` のテンプレートのみが存在し、サイトのコードは存在しない。

## 期待する挙動

* `index.html` をブラウザで開くと、日本語に翻訳されたFAQが一覧表示される。
* キーワード検索とカテゴリ絞り込みでFAQを探せる。
* 質問をクリックすると回答が開閉する。

## 対象範囲・対象外

### 対象範囲

* FAQサイト(`index.html`、`styles.css`、`script.js`、FAQデータJS)の新規作成
* `qa.md` の全質問・回答の日本語翻訳と掲載
* 仕様書・実装計画書の作成

### 対象外

* バックエンド、データベース、API
* ビルドツール、フレームワーク、外部ライブラリ、外部通信
* `qa.md` 自体の変更
* 多言語切替、ダークモード切替、お問い合わせ機能

## 利用者・影響システム

* 利用者: FAQを閲覧する一般利用者
* 影響システム: なし(新規ファイルの追加のみ)

## 主な仕様

1. データ
   * `qa.md` の全17項目を日本語に翻訳して掲載する。固有名詞(Bob、MCP、VS Code 等)およびコード表記(`@/src/file.ts`、`@problems`、`.bob/rules/`、`/` コマンド等)は原文のまま維持する。
   * カテゴリは `qa.md` の見出しに対応させる: 一般 / 使い方 / 高度な機能 / トラブルシューティング。
   * 質問の並び順は `qa.md` の順とする。
   * FAQデータは `faq-data.js` にJavaScriptの配列として保持し、`fetch` は使用しない(`file://` で動作させるため)。
2. 回答の表現
   * 段落、箇条書き、太字、インラインコードを再現する。
3. 検索
   * 質問文と回答文を対象とした部分一致検索。入力ごとに即時絞り込む。
   * 大文字小文字、全角半角(英数字)の違いは区別しない。
4. カテゴリ絞り込み
   * 「すべて」+ 4カテゴリのタブ。選択中のタブを明示する。
   * 検索とカテゴリ絞り込みはAND条件で併用できる。
5. アコーディオン
   * 質問をクリック、またはEnter/Spaceで回答を開閉する。複数項目を同時に開ける。
6. 件数表示
   * 現在の表示件数を「全◯件中 ◯件を表示」の形式で表示する。

## 制約・非機能要件

* 素のHTML/CSS/JavaScriptのみ。外部ライブラリ・CDN・外部フォント・外部通信は使用しない。
* `index.html` をダブルクリックで開くだけで動作する。
* 対応ブラウザ: 現行のモダンブラウザ(Chrome、Edge、Firefox、Safari)。
* アクセシビリティ: 質問ボタンは `button` 要素とし `aria-expanded` / `aria-controls` を設定する。キーボードで全操作可能とし、フォーカスが視認できること。文書の言語は `lang="ja"`。
* ユーザー入力はテキストとして扱い、`innerHTML` へ検索語を挿入しない(XSS防止)。

## UI・画面仕様

### 対象画面

FAQ一覧の単一画面(`index.html`)。ページ遷移なし。

### 画面構成・表示項目

上から順に以下を配置する(単一カラム、最大幅 約800px、中央寄せ)。

```text
+------------------------------------------+
| ヘッダー: 「よくある質問(FAQ)」 + 説明文   |
+------------------------------------------+
| [ キーワードで検索               ] (検索)  |
| [すべて][一般][使い方][高度な機能][トラブル…]|
| 全17件中 17件を表示                        |
+------------------------------------------+
| ▼ 一般(カテゴリ見出し:「すべて」選択時のみ) |
|  ▸ Bobとは何ですか?                        |
|  ▾ Bobはどのように動作しますか?             |
|     回答本文(段落・箇条書き)                |
|  ...                                      |
+------------------------------------------+
| (該当なし時) 空状態メッセージ               |
+------------------------------------------+
| フッター: 元データ qa.md に基づく           |
+------------------------------------------+
```

表示項目:
* ヘッダー: タイトル「よくある質問(FAQ)」、説明文
* 検索ボックス(プレースホルダ付き、クリア可能)
* カテゴリタブ5つ(すべて / 一般 / 使い方 / 高度な機能 / トラブルシューティング)
* 件数表示
* FAQアコーディオン一覧(「すべて」選択時はカテゴリ見出し付き)
* 空状態メッセージ

### 操作・画面遷移

* 質問クリック / Enter / Space: その項目の回答を開閉する。
* 検索入力: 入力ごとに一覧と件数を更新する。
* カテゴリタブ選択: 一覧と件数を更新する。選択中タブは視覚的に強調し `aria-pressed`(または `aria-selected`)で示す。
* 検索クリアボタン: 検索語を空にして全件に戻す。
* 画面遷移はない。

### 表示状態

* 初期表示: 「すべて」選択、検索語なし、全項目を閉じた状態。
* 検索・絞り込み中: 該当項目のみ表示。検索語に一致した箇所の強調表示は行わない。
* 空状態: 該当が0件のとき「該当するFAQが見つかりませんでした。キーワードやカテゴリを変更してお試しください。」を表示し、一覧を非表示にする。
* 読み込み中・エラー: データを同梱するため対象外。
* 絞り込みで該当がないカテゴリは、カテゴリ見出しも非表示にする。

### 入力・バリデーション

* 検索ボックス: 自由入力。文字数制限なし。前後の空白は無視する。空文字は全件対象。
* 入力エラーは発生しない。

### デザイン要件

* 既存のデザインシステムはないため、シンプルで中立的な独自スタイル(白背景、グレー系の文字、アクセントに青系1色)とする。
* レスポンシブ: 幅320px〜PCに対応。狭い画面ではカテゴリタブを折り返す(または横スクロール)。横スクロールが画面全体に発生しないこと。
* タップしやすい高さ(質問ボタンは44px以上を目安)。
* 文字は日本語に適したシステムフォントを使用し、本文の行間は1.6程度。
* 文字と背景のコントラストは読みやすさを確保する。キーボードフォーカスのアウトラインを表示する。

## 確認方法

1. ブラウザで `index.html` を直接開き、全17項目が表示されることを確認する。
2. 各カテゴリタブを切り替え、件数と表示項目が正しいことを確認する。
3. 「MCP」「コマンド」「undo」等で検索し、結果が正しいことを確認する。存在しない語で空状態を確認する。
4. 質問のクリックおよびEnter/Spaceで開閉できることを確認する。
5. ブラウザの幅を変更(約320px〜1280px)して表示を確認する。
6. Tabキーのみで検索・タブ・質問を操作できることを確認する。
7. `qa.md` の項目と翻訳内容を突き合わせる。

## リスク・懸念点

* 翻訳の言い回しは自動翻訳に基づくため、公式な日本語表記と異なる可能性がある。
* 手動確認が中心となる(自動テストは作成しない想定)。ブラウザ実機での確認はこの環境で実施できない場合がある。
* `qa.md` が更新された場合、`faq-data.js` への反映は手動となる。
